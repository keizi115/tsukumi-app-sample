つくみアプリ（サンプル）  PWA版
作成日：2026年10月3日

■ 中身
  index.html             アプリ本体（モック画面）
  manifest.webmanifest   アプリ名・アイコン・全画面表示の設定
  sw.js                  オフライン表示用（一度開いた画面を端末に保存）
  icons/                 ホーム画面用アイコン

■ 使い方
1. このフォルダの中身を、HTTPS（https://〜）で公開できるWebサーバーにそのままアップロードします。
   例：ロリポップの任意のフォルダ（https://hotomaru.jp/tsukumi-app/ など）、GitHub Pages、Netlify
   ※ http:// のサーバーやパソコン内のファイルを直接開いた場合は、アプリとして追加できません。
2. スマホでそのURLを開きます。
   iPhone ：Safariで開く → 共有ボタン → 「ホーム画面に追加」
   Android：Chromeで開く → 右上メニュー → 「ホーム画面に追加」または「アプリをインストール」
3. ホーム画面の「つくみ」アイコンから起動すると、ブラウザの枠なしの全画面で表示されます。

■ 注意
・表示される運航状況、ごみ収集日、店舗、電話番号はすべて説明用のサンプルです。
・内容を更新したときは、sw.js の CACHE 名（tsukumi-app-v1）を v2 などに変えると、端末側の古い保存分が入れ替わります。
